Data quality checks
tests/test_data_quality.py + tests/test_api.py
✓Primary keys unique and non-null
✓Valid plan / segment / feature domains
✓Experiment groups balanced (SRM test)
✓Calls and features reference real customers
✓No activity before signup
✓AI-handled calls only after AI adoption
✓Cohort retention within 0–100%, signup week = 100%
